# More portfolio projects

Each project lives in its own folder under `projects/` as a **zip of the source** with its documentation
and demos next to it, unzipped so they can be read on GitHub.

| # | Project | What it is | Contents |
| - | ------- | ---------- | -------- |
| 1 | [MiniERP](01-minierp) | Products, stock, sales, purchases, invoices and reports on a real SQLite database in the browser (TypeScript, React) | source zip, README, ARCHITECTURE, features page, screenshots, demo video |
| 2 | [Runway](02-runway) | A cash-flow forecast: list income and costs, see the balance month by month and the date the money runs out (TypeScript, React) | source zip, README, features page, screenshots, demo video |

Each folder has: `README.md` (what it is and how to run it), the `*-source.zip`, `docs/` (screenshots) and `demo/` (videos).
To run a project: unzip it, then follow its README.
