Telegram Media Library Bot

Post videos to a private channel with a short caption. The bot files them in a database, and people find them by typing a title and tapping through season and episode.

PythonTelethon (MTProto)SQLiteup to 2 GB files226 tests

Where it stands

Never run against real Telegram. There were no Telegram credentials where it was built. All 226 tests pass offline, using real Telethon message objects and a fake client, and the chat below is simulated the same way. Expect small fixes the first time you connect a real bot.

Use it only for media you have the right to share, and keep it private: set ALLOWED_USER_IDS to the people you choose.

How it works

Set it up

You need Python 3.10 or newer. Five steps, about ten minutes.

  1. Get an api_id and api_hash

    1. Open my.telegram.org and sign in with your phone number.
    2. Choose API development tools and create an application (any name, platform "Other").
    3. Copy the api_id (a number) and the api_hash (32 characters). Keep them secret.

  2. Create the bot

    1. In Telegram, open @BotFather and send /newbot.
    2. Copy the token it gives you (like 123456789:AA...). A bot token is required: only bots can show the buttons.

  3. Make the storage channel

    1. Create a private channel and post one video to it.
    2. Channel settings, Administrators, add your bot (default rights are enough).
    3. Find the channel id: a private post link looks like t.me/c/1234567890/5, so the id is -100 + that number: -1001234567890.

  4. Configure

    python -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env      # then fill it in
    SettingWhat to put
    API_ID, API_HASHfrom step 1
    BOT_TOKENfrom step 2
    STORAGE_CHANNEL_IDfrom step 3 (starts with -100)
    ALLOWED_USER_IDSoptional: user ids allowed to use the bot (get yours from @userinfobot). Empty means anyone who finds it
    ADMIN_IDSoptional: ids that may use /stats and /reindex and are told about problems

  5. Start it

    python bot.py

    The database is created from schema.sql on the first start. (To do it by hand: sqlite3 library.db < schema.sql.) Open your bot in Telegram, press Start, and send a title. To index videos that were already in the channel, send /reindex as an admin.

Write the captions

Each video needs a caption that says what it is. Either style works.

YAML block (recommended)

---
title: "Attack on Titan"
type: Anime
year: 2013
season: 1
episode: 1
resolution: 1080p
genres: [Action, Fantasy]
---

Plain lines

Title: Attack on Titan
Type: Anime
Year: 2013
Season: 1
Episode: 1
Resolution: 1080p
#Action #Fantasy
  • A title is required. A post without one is skipped and the admins get a message naming the post. Edit its caption and it is indexed.
  • Types: Movie, Anime or Show (tv, series, film also work). A missing type is guessed (Show if there is a season or episode, otherwise Movie, never Anime).
  • Bad values are ignored, not stored: a year outside 1880 to five years ahead, a negative or non-numeric season or episode.
  • The same title, type and year is one entry however many episodes or qualities you upload. "Dune" 1984 and "Dune" 2021 stay separate.
  • Audio versions: put them in the resolution text, for example resolution: 1080p Dub.

Commands

CommandWhoWhat it does
any text, or /search wordsallowed usersfind titles containing every word, in any order and case
/start, /helpallowed usersshort help
/statsadminshow many titles and files are in the library
/reindex [first] [last]adminsread the channel's posts by id and index them; stops after 300 empty ids in a row

When something goes wrong

What you seeWhat it means and what to do
The bot says it cannot reach the storage channelMake sure the bot is an administrator of the channel and the id starts with -100. Then post anything in the channel once, so the bot learns it.
An admin message: "Skipped message 106"That post's caption has no title. Edit the caption; the bot indexes it when it sees the edit.
A video is not found by searchIt was posted before the bot joined: send /reindex. Or its caption was skipped (see above).
"Sorry, that file is no longer available."The post was deleted from the channel. The bot forgot the file and told the admins. Upload it again.
"Telegram is limiting this bot"Telegram asked the bot to wait more than five minutes. Try again after the time shown.
"That search has expired"The bot restarted since that menu was shown. Send your search again.
"This library is private."Your user id is not in ALLOWED_USER_IDS.

Limits to know about

  • Never run against real Telegram (see the top of this page).
  • Search matches words in the title only, not genre, year or description.
  • The specified schema makes message ids unique on their own, so the library supports one storage channel.
  • I changed a few things from the original specification (a unique index on titles, pyyaml in the requirements, validated caption fields). They are listed in the README.
  • Whether sharing a given video is allowed is your responsibility.
