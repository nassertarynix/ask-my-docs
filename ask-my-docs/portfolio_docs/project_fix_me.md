# Project: Fix Me

Fix Me is a personal tracker app with the tagline "One private place for your day." It tracks tasks, prayers, workouts, habits, streaks, and money in one app. Everything stays on the phone: there is no account and no internet connection needed. It offers reminders, weekly statistics, home-screen widgets, and a Home screen the user arranges themselves.

## Status and role

Fix Me is Al-Nasser Haddad's own product. On the portfolio he is listed as Creator, Product and UI/UX Designer, and Mobile Developer. Its status is "v1, In Testing". It has no public GitHub repository link on the portfolio.

## Tech stack

Fix Me is built with Flutter and uses Cubit for state management and SQLite for local storage.

## Problem and solution

- Problems: scattered apps for habits, money and prayers, nothing private by default, reminders that stop working, and screens that do not adapt to what a person tracks.
- Solution: one local-first app with modular sections the user chooses, a customizable Home, reminders that survive not opening the app, and statistics across everything.

## Key features

Customizable Home, modular sections, smart reminders, statistics, home-screen widgets, and private-by-design storage.

## Challenges

Reliable reminders and exact alarms on Android, a glass UI that stays fast on older phones, safe backups, restores and resets, and keeping many screens consistent.

## Technical decisions and learnings

- SQLite for local storage.
- Cubit for state.
- Repositories and pure planners for testability.
- One design system with tokens.
- Modular registries for sections and statistics.
- Learnings: BLoC architecture, UX-driven planning, and a scalable structure.

## UI/UX design work on Fix Me

Fix Me is also featured as Al-Nasser Haddad's UI/UX design work. It has a glass-style design system with surfaces, tokens, spacing rules, and light and dark modes. It has a customizable dashboard and components that stay readable on small screens, with shrink-to-fit text and tiles that swipe. Early concepts were generated with Stitch, while the decisions and the design system built in Flutter are Al-Nasser's own. Design skills shown: design system and tokens, dashboard layout and information hierarchy, responsive small-screen behaviour, and dark mode.
