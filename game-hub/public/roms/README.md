# Your own games

Put ROM files you own in this folder (sub-folders are fine), then run `npm run dev` or `npm run build`.
They appear on the Retro Deck as cards: click one and it plays.

Supported: `.nes` (NES), `.sfc` `.smc` (SNES), `.md` `.gen` `.smd` (Mega Drive / Genesis), `.gb` `.gbc` (Game Boy), `.gba` (Game Boy Advance).

Everything in this folder except this file is ignored by git, so nothing you put here is ever committed.
Commercial games are copyrighted: keep them on your own machine or a private, access-controlled deployment,
and do not publish a build that contains them.
